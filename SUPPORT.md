# PromptDe Support

## Start here

1. Read the [installation and first-use guide](README.md#install-promptde).
2. Confirm you are using the latest [PromptDe release](https://github.com/ITISH7/PromptDe/releases/latest).
3. Search [existing issues](https://github.com/ITISH7/PromptDe/issues) for the same problem.
4. If the problem remains, choose the matching [issue form](https://github.com/ITISH7/PromptDe/issues/new/choose).

When asking for help, include your operating system, PromptDe version, installation method, display server on Linux, what you expected, and the exact error message.

Never post API keys, private transcripts, recordings, clipboard contents, or an unredacted `.env` file.

Security vulnerabilities must be reported through the [private security form](https://github.com/ITISH7/PromptDe/security/advisories/new), not a public issue.
