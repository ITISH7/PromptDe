# PromptDe Roadmap

This roadmap describes the current direction of PromptDe. Priorities may change based on user feedback, platform constraints, and contributor interest; listed items are not release commitments.

## Near term

- Improve first-run setup and API-key validation.
- Make global shortcut and paste behavior more reliable across X11, Wayland, Windows, and macOS.
- Expand accessibility, keyboard navigation, and screen-reader coverage.
- Add clearer provider error recovery and model availability guidance.
- Improve signed and notarized desktop release coverage.
- Grow automated tests for desktop workflows and platform-specific paths.

## Exploring

- Reusable prompt templates for common development tasks.
- User-defined prompt modes and compilation instructions.
- Optional local history with explicit privacy controls.
- More transcription and prompt providers.
- Additional interface and documentation languages.
- An offline transcription option where platform support allows it.

## Community priorities

Open a [feature request](https://github.com/ITISH7/PromptDe/issues/new?template=feature_request.yml) to propose an item or explain which roadmap problem matters most to you. Please discuss large features before starting implementation.

Completed work is recorded in the [changelog](CHANGELOG.md).
